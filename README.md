# test-repo

Public repo, not published to npm. Run via npx from GitHub:

```sh
npx github:asdiAdi/test-repo init
npx github:asdiAdi/test-repo run
npx github:asdiAdi/test-repo test
```

| Command | Does |
|---|---|
| `init` | scaffolds `.github/workflows/deploy.yaml` |
| `run` | prints `Hello World` |
| `test` | scaffolds `test.html` with TFT Set 18 champions (name, traits, description) |
